1. Το Σενάριο 
Τίτλος Εφαρμογής: Σύστημα Διαχείρισης Πελατών & Παραγγελιών Βιομηχανικού Εξοπλισμού 
Περιγραφή: Η παρούσα διαδικτυακή εφαρμογή αναπτύχθηκε στα πλαίσια του ψηφιακού μετασχηματισμού (Industry 4.0) και εστιάζει στον τομέα της Ψηφιακής Βιομηχανίας. Αποτελεί ένα ολοκληρωμένο σύστημα διαχείρισης πωλήσεων που επιτρέπει σε μια εμπορική ή κατασκευαστική εταιρεία να ψηφιοποιήσει πλήρως το πελατολόγιό της και τη ροή των παραγγελιών της.
Το πρόβλημα που λύνει: Σε πολλές βιομηχανικές και εμπορικές επιχειρήσεις, η καταγραφή πελατών (B2B/B2C) και η διαχείριση των παραγγελιών τους γίνεται συχνά με μη αυτόματους τρόπους ή μέσω κατακερματισμένων αρχείων (π.χ. Excel). Αυτό οδηγεί σε καθυστερήσεις, λάθη στην καταχώρηση ειδών (όπως ανταλλακτικά, κινητήρες, τεχνολογικός εξοπλισμός) και δυσκολία στην παρακολούθηση του ιστορικού.
Η λύση και η λειτουργικότητα: Η εφαρμογή παρέχει ένα κεντρικό, φιλικό προς τον χρήστη περιβάλλον με τρεις βασικούς πυλώνες:
1.	Διαχείριση Πελατολογίου: Φόρμα άμεσης καταχώρησης νέων πελατών με τα βασικά στοιχεία επικοινωνίας τους (Όνομα/Επωνυμία, Email, Τηλέφωνο).
2.	Δημιουργία Παραγγελιών: Δυναμική φόρμα όπου ο χρήστης επιλέγει τον πελάτη, αναζητά το επιθυμητό προϊόν από τον κατάλογο της αποθήκης, ορίζει ποσότητες και προσθέτει είδη σε ένα ψηφιακό καλάθι.
3.	Ιστορικό & Προβολή (Αρχική): Ένας συγκεντρωτικός πίνακας ελέγχου που προβάλλει σε πραγματικό χρόνο το ιστορικό όλων των παραγγελιών, με λεπτομέρειες αγορών και χρονοσημάνσεις 
Σε ποιους απευθύνεται: Το σύστημα προορίζεται για εσωτερική χρήση από το τμήμα πωλήσεων, τους διαχειριστές αποθήκης και το διοικητικό προσωπικό της εκάστοτε επιχείρησης.
2. Αρχιτεκτονική της Εφαρμογής (Application Architecture)
Η εφαρμογή ακολουθεί την κλασική αρχιτεκτονική πελάτη-εξυπηρετητή (Client-Server) και έχει αναπτυχθεί με χρήση τεχνολογιών Ιστού (Web Technologies). Είναι δομημένη έτσι ώστε να διαχωρίζει τη διεπαφή χρήστη (Frontend), τη λογική της εφαρμογής (Backend) και τη διαχείριση των δεδομένων.
Τεχνολογίες που χρησιμοποιήθηκαν (Tech Stack):
•	Frontend (Διεπαφή Χρήστη): * HTML5 & CSS3: Για τη δομή και τη μορφοποίηση των σελίδων (style.css), προσφέροντας ένα καθαρό και φιλικό προς τον χρήστη περιβάλλον.
o	JavaScript: (script.js) Για δυναμική αλληλεπίδραση στο περιβάλλον του χρήστη (π.χ. προσθήκη στο καλάθι, έλεγχος φορμών πριν την υποβολή).
•	Backend (Λογική Διακομιστή):
o	PHP: Χρησιμοποιείται για την επεξεργασία των δεδομένων, τη διαχείριση των φορμών και την επικοινωνία με τη βάση δεδομένων.
•	Βάση Δεδομένων: * MySQL / MariaDB: Σχεσιακή βάση δεδομένων για την ασφαλή αποθήκευση πελατών και παραγγελιών (Η διαχείριση της σύνδεσης γίνεται μέσω PDO ή MySQLi).
Δομή Αρχείων (File Structure): Το project είναι οργανωμένο με καθαρό τρόπο σε επίπεδο αρχείων:
•	index.php: Η αρχική σελίδα (Dashboard) που προβάλλει τον συγκεντρωτικό πίνακα με τη λίστα των πελατών και των παραγγελιών τους.
•	add_customer.php: Το script που αναλαμβάνει τη φόρμα καταχώρησης και την αποθήκευση ενός νέου πελάτη στη βάση.
•	add_order.php: Το script που διαχειρίζεται τη διαδικασία δημιουργίας παραγγελίας (επιλογή πελάτη, προϊόντος, ποσότητας).
•	db.php: Το αρχείο διαμόρφωσης που περιέχει τα διαπιστευτήρια και τη λογική για τη σύνδεση του συστήματος με τη βάση δεδομένων.
•	style.css: Εδώ βρίσκεται όλη η οπτική μορφοποίηση της εφαρμογής.
•	script.js: Περιέχει τον κώδικα JavaScript για λειτουργίες στο πλευρό του πελάτη (client-side).

•	Αναλυτικά τα σχήματα (schemas) των πινάκων:
•	Πίνακας: customers (Πελατολόγιο)

4. Διαδικασία Ανάπτυξης της Εφαρμογής (Development Process)
Η ανάπτυξη της εφαρμογής ακολούθησε μια γραμμική μεθοδολογία υλοποίησης (από τον κώδικα διεπαφής προς τη διαχείριση δεδομένων), η οποία χωρίστηκε στα εξής βασικά στάδια:
1.	Υλοποίηση Διεπαφής & Βασικής Λογικής (Frontend/PHP): Σε πρώτο χρόνο, αναπτύχθηκε ο δομικός κώδικας (HTML/PHP) για τις τρεις κύριες σελίδες της εφαρμογής (Αρχική προβολή λίστας, Φόρμα νέου πελάτη, Φόρμα νέας παραγγελίας).
2.	Σχεδιασμός UI/UX (Styling): Στη συνέχεια, δημιουργήθηκε το αρχείο style.css για την οπτική μορφοποίηση της εφαρμογής. Δόθηκε έμφαση στη δημιουργία ενός καθαρού και επαγγελματικού περιβάλλοντος (π.χ. χρωματική κωδικοποίηση κουμπιών, στοίχιση φορμών, ευανάγνωστοι πίνακες δεδομένων).
3.	Διαμόρφωση Βάσης Δεδομένων (Database Design): Αφού ολοκληρώθηκε το περιβάλλον χρήστη, σχεδιάστηκε η βάση δεδομένων industry_db και δημιουργήθηκαν οι απαραίτητοι πίνακες.
4.	Διασύνδεση & Έλεγχος (Integration & Testing): Το τελικό βήμα αφορούσε τη συγγραφή του αρχείου σύνδεσης (db.php) και την ενσωμάτωση των SQL ερωτημάτων (INSERT, SELECT) μέσα στις σελίδες της PHP, ώστε η εφαρμογή να είναι πλήρως λειτουργική και να επικοινωνεί δυναμικά με τη βάση.
5. Δικτυακή Αρχιτεκτονική (Network Architecture)
Για τους σκοπούς της ανάπτυξης και της παρουσίασης, η εφαρμογή λειτουργεί σε τοπικό περιβάλλον (Local Development Environment), κάνοντας χρήση του XAMPP stack.
Η δικτυακή αρχιτεκτονική βασίζεται στα εξής:
•	Τοπικός Διακομιστής (Localhost): Η εφαρμογή φιλοξενείται τοπικά στη διεύθυνση 127.0.0.1 (localhost).
•	Web Server: Χρησιμοποιείται ο Apache HTTP Server (μέσω του XAMPP) για την εξυπηρέτηση των αρχείων της εφαρμογής (HTML, CSS, JS) και την εκτέλεση του κώδικα PHP μέσω της προεπιλεγμένης θύρας (port) 80.
•	Database Server: Η διαχείριση της βάσης δεδομένων γίνεται μέσω του MariaDB/MySQL server (επίσης ενσωματωμένο στο XAMPP), το οποίο "ακούει" στην προεπιλεγμένη θύρα 3306.
•	Διαχείριση: Η οπτική διαχείριση του server και της βάσης πραγματοποιείται μέσω του ενσωματωμένου εργαλείου phpMyAdmin.
